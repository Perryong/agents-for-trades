**2. Create `frontend/src/hooks/useTradeStatus.ts`** (per D-06, research Pattern 10):
- Accept `ticker: string` and `orderId: string | null`
- When `orderId` is non-null, start polling `GET /api/trades/${ticker}/status?order_id=${orderId}` every 3000ms
- Stop polling when status is in terminal set: `['filled', 'rejected', 'error']`
- Return `TradeStatus` object
- Cleanup interval on unmount or orderId change
- Use `window.setInterval` (not requestAnimationFrame)

**3. Create `frontend/src/hooks/useTrade.ts`:**
- Export `useTrade()` hook returning `{ submitTrade, isSubmitting }`
- `submitTrade(req: TradeRequest)` does `fetch('/api/trades', { method: 'POST', headers: {'Content-Type': 'application/json'}, body: JSON.stringify(req) })`
- Returns `TradeResponse` on success, throws on error
- `isSubmitting` state boolean for loading UI
