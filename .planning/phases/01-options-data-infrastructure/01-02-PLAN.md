    - Creates `yf.Ticker(symbol.upper())`

    **`get_options_chain(symbol: str, expiration: str) -> str`:**
    - Uses `get_cached_text` with prefix `"yfinance_options_chain"`, payload `{"symbol": symbol.upper(), "expiration": expiration}`, TTL `OPTIONS_CHAIN_CACHE_TTL_SECONDS`
    - Inner fetcher: calls `yf.Ticker(symbol.upper()).option_chain(expiration)`
    - Concatenates `chain.calls` and `chain.puts` DataFrames
    - Renames columns to match Tradier contract: `openInterest` -> `open_interest`, `impliedVolatility` -> `iv`
    - Adds `option_type` column: "call" for calls rows, "put" for puts rows
    - Adds `expiration_date` column set to the `expiration` parameter
    - Adds None columns for: `delta`, `gamma`, `theta`, `vega` (yfinance has no greeks)
    - Selects columns: `strike`, `expiration_date`, `option_type`, `bid`, `ask`, `volume`, `open_interest`, `delta`, `gamma`, `theta`, `vega`, `iv`
    - Returns `df.to_string(index=False)`
    - If empty, returns `"No options data available for {symbol} expiring {expiration}"`

    **`get_historical_iv(symbol: str, weeks: int = 52) -> str`:**
    - Uses `get_cached_text` with prefix `"yfinance_historical_iv"`, payload `{"symbol": symbol.upper(), "weeks": weeks}`, TTL `HISTORICAL_IV_CACHE_TTL_SECONDS`
    - Inner fetcher:
      1. Gets expirations via `get_options_expirations(symbol)`
      2. For each expiration, fetches chain and computes median `impliedVolatility` from calls as ATM IV proxy
      3. Builds `[{"date": exp, "iv": median_iv}]` list
      4. Returns `pd.DataFrame(records).to_string(index=False)` or `"No historical IV data available for {symbol}"` if empty
