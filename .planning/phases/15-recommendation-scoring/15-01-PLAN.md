```python
def _extract_price(text: str, label: str) -> float | None:
    patterns = [
        rf"{label}\s*(?:price)?[:\s]*\$?([\d,.]+)",
        rf"\$?([\d,.]+)\s*{label}",
    ]
    for pat in patterns:
        m = re.search(pat, text, re.IGNORECASE)
        if m:
            try: return float(m.group(1).replace(",", ""))
            except ValueError: continue
    return None
```

    **api/schemas.py** — Add two new response models:

    ```python
    class ScoreSummaryResponse(BaseModel):
        win_rate: float              # percentage 0-100
        expectancy: float            # average P&L per trade (dollar-equivalent %)
        avg_winner: float            # average P&L % of winning trades
        avg_loser: float             # average P&L % of losing trades
        profit_factor: float         # sum(winners) / abs(sum(losers)), 0 if no losers
        total_trades: int            # all trades in DB
        total_closed: int            # trades with outcome != None
        disclaimer: Optional[str] = None  # present when <5 closed trades

    class CalibrationBucket(BaseModel):
        bucket_label: str            # "0-20%", "20-40%", etc.
        bucket_min: int
        bucket_max: int
        actual_win_rate: float       # 0-100
        trade_count: int

    class CalibrationResponse(BaseModel):
        buckets: list[CalibrationBucket]
        total_scored: int            # trades with non-null confidence + outcome
        message: Optional[str] = None  # "Need 10+ scored trades..." when insufficient
    ```

    **api/score_routes.py** — New file. Create `score_router = APIRouter(prefix="/api")`.

    `GET /api/scores/summary` — Query all trades, compute:
    - total_trades = count(all)
    - total_closed = count(where outcome is not None)
    - wins = [t for t in closed if t.outcome == "WIN"]
    - losses = [t for t in closed if t.outcome == "LOSS"]
    - win_rate = len(wins) / total_closed * 100 (0 if no closed)
    - avg_winner = mean(pnl_pct for wins) or 0.0
    - avg_loser = mean(pnl_pct for losses) or 0.0
    - expectancy = (win_rate/100 * avg_winner) + ((1 - win_rate/100) * avg_loser)
    - profit_factor = sum(pnl_pct for wins) / abs(sum(pnl_pct for losses)) if losses else 0.0
    - disclaimer = "Based on N trades -- insufficient sample for statistical significance." if total_closed < 5 (per D-08)
    Per D-06: all metrics returned together, never win_rate alone.

    `GET /api/scores/calibration` — Query closed trades with non-null confidence:

    - For each bucket: actual_win_rate = wins_in_bucket / total_in_bucket * 100
    - Return CalibrationResponse with buckets list
