    Create the screener subpackage directory and files:

    1. **tradingagents/agents/screener/screener_agent.py** -- Define:

       - `TopPick(BaseModel)` with fields:
         - `ticker: str`
         - `score: float = Field(ge=0.0, le=1.0)` (confidence the LLM assigns)
         - `rationale: str`
         - `confidence: float = Field(ge=0.0, le=1.0)`
         - `key_metrics: dict = Field(default_factory=dict)` (volume_ratio, momentum_5d; sector and market_cap as Optional per Open Question 1 in RESEARCH.md -- make them Optional[str] = None on TopPick itself)

       - `ScreenerResult(BaseModel)` with fields:
         - `picks: list[TopPick]`
         - `screened_at: datetime`
         - `candidate_count: int`
         - `model_used: str`
         - `error: Optional[str] = None` (populated on partial-result degradation)

       - `SYSTEM_PROMPT` constant: instruct the LLM to respond with ONLY a JSON object (no preamble, no markdown fences) containing a `picks` array. Each pick must have `ticker`, `score` (float 0.0-1.0), `rationale` (1-2 sentences), `confidence` (float 0.0-1.0), `key_metrics` dict. Include scoring rubric: volume momentum signals high urgency, sector diversification preferred, penalize identical-sector clustering.

       - `_format_candidates_for_prompt(candidates: list[ScreenerCandidate]) -> str`: project each candidate to ticker, composite_score, volume_score, momentum_score only. Format as a numbered list. Do NOT include raw DataFrames or coverage_note.

       - `_parse_screener_response(content: str, n_picks: int) -> ScreenerResult | None`: strip markdown fences with regex `r'```(?:json)?\s*([\s\S]*?)\s*```'`, then `json.loads()`, then `ScreenerResult.model_validate()`. Return None on JSONDecodeError or ValidationError.

       - `create_screener_agent(llm)`: factory returning a closure `screener_agent(candidates: list[ScreenerCandidate], config: dict) -> ScreenerResult`. The closure:
         - Reads `n_picks = min(config.get("screener_n_picks", 5), 10)`
         - Calls `_format_candidates_for_prompt(candidates)`
         - Builds `ChatPromptTemplate.from_messages([("system", SYSTEM_PROMPT), ("human", candidate_text)])`
         - Calls `(prompt | llm).invoke({})`
         - Calls `_parse_screener_response(result.content, n_picks)`
         - On None return (parse failure): retry once with a stricter prompt that includes "Respond with ONLY valid JSON. No text before or after." prefix
         - On second failure: build a partial `ScreenerResult` from the top n_picks candidates by composite_score, with rationale="Auto-selected by composite score (LLM parse failed)", error="LLM response could not be parsed after retry"
         - Sets `screened_at=datetime.now(timezone.utc)`, `candidate_count=len(candidates)`, `model_used=str(type(llm).__name__)`

       - `run_screener(config: dict, llm) -> ScreenerResult`: public entry point.
         - Calls `get_screener_signals(max_candidates=config.get("screener_max_candidates", 50))`
         - Creates agent via `create_screener_agent(llm)`
         - Calls agent with `(candidates, config)`
         - Validates result is `ScreenerResult` -- if not, raises `TypeError("Expected ScreenerResult, got {type}. ScreenerResult must never enter AgentState.")`
         - Returns result

       - `_validate_not_agent_state(obj) -> None`: helper called at `run_screener` entry. If `obj` is an instance of dict with keys matching AgentState fields ("company_of_interest", "trade_date", "messages"), raise `TypeError("ScreenerResult must not be passed as AgentState")`. This is the RANK-03 isolation guard.
