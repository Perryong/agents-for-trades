**Pydantic model `ScreenerCandidate`:**
```python
from pydantic import BaseModel
from typing import Optional

class ScreenerCandidate(BaseModel):
    ticker: str
    volume_score: float        # normalized [0, 1]
    momentum_score: float      # normalized [0, 1]
    unusual_activity_score: float  # normalized [0, 1]
    composite_score: float     # equal-weight mean of three scores
    rank: int                  # 1-indexed rank (1 = best)
    coverage_note: Optional[str] = None
```

**Function `get_sp500_tickers() -> list[str]`:**
- Use `pd.read_html("https://en.wikipedia.org/wiki/List_of_S%26P_500_companies", attrs={"id": "constituents"})`
- Try column `"Symbol"`, fall back to `df.columns[0]`
- Replace "." with "-" in ticker symbols (yfinance convention: BRK.B -> BRK-B)
- Wrap in try/except, raise `RuntimeError("Failed to fetch S&P 500 ticker list from Wikipedia")` on failure

**Function `_fetch_chunk(tickers: list[str], period: str = "25d") -> dict[str, pd.DataFrame]`:**
- Call `yf.download(tickers, period=period, auto_adjust=True, progress=False, group_by="ticker")`
- On success, iterate tickers, try `raw[ticker].dropna(how="all")`, skip KeyError/TypeError
- On `YFRateLimitError`, retry up to MAX_RETRIES with exponential backoff: `wait = BACKOFF_BASE ** (attempt + 1)` plus random jitter `random.uniform(0, 1)`
- Return dict of {ticker: DataFrame} for successful tickers

**Function `fetch_universe_data(tickers: list[str] | None = None, chunk_size: int = CHUNK_SIZE) -> tuple[dict[str, pd.DataFrame], float]`:**
- If tickers is None, call `get_sp500_tickers()`
- Split tickers into chunks of `chunk_size`
- Call `_fetch_chunk` per chunk, merge results
- Compute coverage = `len(all_data) / len(tickers)` (0.0 if no tickers)
- Return `(all_data, coverage)`

**Function `_get_session_key() -> str | None`:**
- Get current time in UTC as `pd.Timestamp(datetime.now(pytz.utc))`
- Call `_xnys.is_trading_minute(now_utc)` — if True, return `now_et.strftime("%Y-%m-%d")`
- If not trading, return None

**Functions `_cache_get(session_key: str) -> list[ScreenerCandidate] | None` and `_cache_set(session_key: str, results: list[ScreenerCandidate]) -> None`:**
- `_cache_get`: Check `_SCREENER_CACHE[session_key]`, if exists and `time.time() - ts <= _CACHE_TTL_SECONDS` return results, else delete and return None
- `_cache_set`: Store `(results, time.time())` in `_SCREENER_CACHE[session_key]`

**Function `_compute_signals(universe_data: dict[str, pd.DataFrame]) -> pd.DataFrame`:**
- For each ticker with >= 21 rows of data:
  - `volume_ratio = current_vol / avg_20_vol` (avg of last 20 days excluding current)
  - `momentum_5d = (close[-1] - close[-6]) / close[-6]` (5-day return; need >= 6 rows)
  - `price_change_1d = (close[-1] - close[-2]) / close[-2]`
  - `unusual_activity = float(volume_ratio > 2.0 and abs(price_change_1d) > 0.015)`
- Min-max normalize each of `volume_ratio`, `momentum_5d`, `unusual_activity` to [0, 1]
  - Formula: `(x - x.min()) / (x.max() - x.min())` — if range is 0, use 0.5
- `composite_score = (volume_ratio_score + momentum_5d_score + unusual_activity_score) / 3.0`
- Sort by composite_score descending, reset index

**Function `get_screener_universe(tickers: list[str] | None = None) -> tuple[dict[str, pd.DataFrame], float]`:**
- Public API for VENDOR_METHODS. Delegates to `fetch_universe_data(tickers)`.

**Function `get_screener_signals(universe_data: dict[str, pd.DataFrame] | None = None, max_candidates: int = 50) -> tuple[list[ScreenerCandidate], float]`:**
- Public API for VENDOR_METHODS.
- If `universe_data` is None, call `fetch_universe_data()` to get it (with coverage).
- Check session cache: `session_key = _get_session_key()`. If session_key and `_cache_get(session_key)` returns results, return `(cached_results, 1.0)`.
- Call `_compute_signals(universe_data)` to get scored DataFrame.
- Take top `max_candidates` rows, convert to `ScreenerCandidate` objects with 1-indexed rank and `coverage_note` like `"487/503 tickers fetched (96.8%)"`.
- If session_key, call `_cache_set(session_key, candidates)`.
- Return `(candidates, coverage)`.

**Module docstring:** Document that min-max normalization is relative ranking (not absolute), so "best picks" during a broad selloff may still have negative momentum. This is expected behavior for a relative screener.

**Helper — create synthetic OHLCV DataFrame for a ticker:**
```python
def _make_ohlcv(n_days=25, base_close=100.0, base_volume=1_000_000, last_volume_mult=1.0, last_close_change=0.0):
    """Create a synthetic OHLCV DataFrame with n_days rows."""
    dates = pd.date_range(end="2026-04-01", periods=n_days, freq="B")
    close = [base_close] * (n_days - 1) + [base_close * (1 + last_close_change)]
    volume = [base_volume] * (n_days - 1) + [int(base_volume * last_volume_mult)]
    return pd.DataFrame({
        "Open": close, "High": close, "Low": close, "Close": close, "Volume": volume
    }, index=dates)
```
