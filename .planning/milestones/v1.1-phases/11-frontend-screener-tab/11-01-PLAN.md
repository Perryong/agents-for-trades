**2. Create frontend/src/hooks/useScreener.ts** mirroring the useAnalysis pattern (useReducer + useCallback):

- Define `ScreenerAction` union type with 4 variants: `FETCH_START`, `FETCH_SUCCESS` (with picks + screenedAt), `FETCH_ERROR` (with message), `RESET`
- Define `initialState: ScreenerState` with status `'idle'`, empty picks array, null screenedAt, null errorMsg
- Define `reducer` function handling all 4 action types:
  - `FETCH_START`: set status to `'loading'`, clear errorMsg, keep existing picks (so UI shows old data during refresh)
  - `FETCH_SUCCESS`: set status `'done'`, replace picks and screenedAt, clear errorMsg
  - `FETCH_ERROR`: set status `'error'`, set errorMsg, keep status as `'error'`
  - `RESET`: return initialState
- Export `useScreener` function:
  - Uses `useReducer(reducer, initialState)`
  - Exposes `runScreen` callback (async, wrapped in `useCallback([], [])`)
  - `runScreen` dispatches `FETCH_START`, then calls `fetch('/api/screen', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ max_picks: 5, universe: 'sp500', llm_provider: 'openai', quick_think_llm: 'gpt-5-mini' }) })`
  - On non-ok response: dispatch `FETCH_ERROR` with `API error ${res.status}`
  - On ok response: parse JSON, check `json.status === 'error'` and dispatch error with `json.data?.error ?? 'Screener error'`
  - On success/partial: dispatch `FETCH_SUCCESS` with `picks: json.data.picks` and `screenedAt: json.screened_at`
  - Catch block: dispatch `FETCH_ERROR` with error message
  - Return `{ state, runScreen }`

```typescript
function getRelativeTime(isoString: string): string {
  const diffMs = Date.now() - new Date(isoString).getTime();
  const diffMin = Math.floor(diffMs / 60_000);
  if (diffMin < 1) return 'just now';
  const rtf = new Intl.RelativeTimeFormat('en', { numeric: 'auto' });
  if (diffMin < 60) return rtf.format(-diffMin, 'minute');
  return rtf.format(-Math.floor(diffMin / 60), 'hour');
}

function isStale(isoString: string): boolean {
  if (!isoString) return false;
  return Date.now() - new Date(isoString).getTime() > 15 * 60 * 1000;
}
```
