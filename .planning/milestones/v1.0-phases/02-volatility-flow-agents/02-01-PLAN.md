    Implement `tradingagents/agents/options/volatility_analyst.py` with the single-pass architecture per CONTEXT.md decisions:

    1. **Helper: `_parse_tabular_string(s: str) -> pd.DataFrame | None`**
       Parse whitespace-aligned tabular string from data layer using `pd.read_csv(io.StringIO(s), sep=r'\s+', engine='python')`. Return None if string is empty or starts with "No ".

    2. **Helper: `_compute_iv_metrics(iv_series: pd.Series, current_iv: float) -> dict`**
       - `iv_rank = (current_iv - iv_min) / (iv_max - iv_min) * 100` (return 50.0 if max == min)
       - `iv_pct = (iv_series < current_iv).mean() * 100`
       - Return `{"iv_rank": round(iv_rank, 1), "iv_pct": round(iv_pct, 1)}`

    3. **Helper: `_compute_hv30(ticker: str) -> float | None`**
       - `yf.Ticker(ticker).history(period="3mo")`
       - `hist["Close"].pct_change().rolling(21).std().iloc[-1] * math.sqrt(252) * 100`
       - Return None on any exception or empty history

    4. **Helper: `_compute_skew(chain_df: pd.DataFrame) -> str`**
       Per Research Pattern 6: compare OTM put IV to OTM call IV. Primary: delta-based (0.20-0.30 range). Fallback: moneyness quartile-based. Return "Put skew elevated (+X.XX%)", "Call skew elevated (X.XX%)", or "Flat skew (+X.XX%)". Threshold: 0.02 absolute difference.

    5. **Helper: `_compute_term_structure(near_chain_df, far_chain_df) -> str`**
       Per Research Pattern 7: compare median IV of near vs far chain. Return "Contango (near X.X%, far X.X%)", "Backwardation (near X.X%, far X.X%)", or "Flat (X.X% near, X.X% far)". Threshold: 0.01.

    6. **Factory: `create_volatility_analyst(llm)`**
