2. Create `frontend/src/components/ProgressStepper.tsx`:

Props interface:
```typescript
interface ProgressStepperProps {
  completedNodes: string[];
  currentNode: string | null;
  enableOptions: boolean;
  status: AnalysisStatus;
}
```

The component builds a full node list from the constants in types.ts:
```typescript
import { EQUITY_NODES, OPTIONS_NODES, RESEARCH_NODES, TRADING_NODES, RISK_NODES, AnalysisStatus } from '../types';

function getNodeList(enableOptions: boolean): string[] {
  return [
    ...EQUITY_NODES,
    ...(enableOptions ? OPTIONS_NODES : []),
    ...RESEARCH_NODES,
    ...TRADING_NODES,
    ...RISK_NODES,
  ];
}
```

For each node, derive status:
- `'done'` if `completedNodes.includes(node)`
- `'running'` if `currentNode === node`
- `'pending'` otherwise

Render as vertical stepper (Tailwind):
- Container: `<div className="space-y-1">`
- Each step: `<div className="flex items-center gap-3 py-1">` containing:
  - Status dot: `<div className={`w-6 h-6 rounded-full flex items-center justify-center text-xs font-bold ${statusClass}`}>` where statusClass is:
    - pending: `"bg-gray-200 text-gray-400"`
    - running: `"bg-blue-500 text-white animate-pulse"`
    - done: `"bg-green-500 text-white"`
  - Icon: done = checkmark character, running = "...", pending = empty circle
  - Label: `<span className={`text-sm ${status === 'done' ? 'text-gray-700' : status === 'running' ? 'text-blue-700 font-medium' : 'text-gray-400'}`}>{node}</span>`
- When `status === 'idle'`, show a muted message: `<p className="text-sm text-gray-400">Configure and click Analyze to start</p>`
