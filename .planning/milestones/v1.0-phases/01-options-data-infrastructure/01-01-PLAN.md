    Create `tradingagents/dataflows/tradier_utils.py` with the following structure:

    **Constants:**
    - `TRADIER_PRODUCTION_URL = "https://api.tradier.com/v1"`
    - `TRADIER_SANDBOX_URL = "https://sandbox.tradier.com/v1"`
    - `OPTIONS_CHAIN_CACHE_TTL_SECONDS = 6 * 60 * 60` (6 hours)
    - `HISTORICAL_IV_CACHE_TTL_SECONDS = 6 * 60 * 60` (6 hours)

    **Exception class:**
    - `class TradierRateLimitError(Exception)` with docstring "Exception raised when Tradier API rate limit (429) is exceeded."

    **Internal helpers:**
    - `_get_api_key() -> str`: reads `os.getenv("TRADIER_API_KEY")`, raises `ValueError("TRADIER_API_KEY environment variable is not set.")` if None
    - `_get_base_url() -> str`: reads `os.getenv("TRADIER_SANDBOX", "true")` — defaults to "true" (sandbox) for safety. Returns `TRADIER_SANDBOX_URL` if "true", else `TRADIER_PRODUCTION_URL`
    - `_make_request(endpoint: str, params: dict) -> dict`: builds headers `{"Authorization": f"Bearer {_get_api_key()}", "Accept": "application/json"}`, constructs URL as `f"{_get_base_url()}{endpoint}"`, calls `requests.get(url, params=params, headers=headers)`, checks `response.status_code == 429` -> raises `TradierRateLimitError(f"Tradier rate limit exceeded. Available: {response.headers.get('X-Ratelimit-Available', 'unknown')}")`, otherwise `response.raise_for_status()`, returns `response.json()`

    **Public functions:**

    `get_options_expirations(symbol: str) -> list[str]`:
    - Calls `_make_request("/markets/options/expirations", {"symbol": symbol.upper(), "includeAllRoots": "true"})`
    - Extracts `data.get("expirations") or {}`
    - Gets `dates = expirations.get("date") or []`
    - If `isinstance(dates, str)`: `dates = [dates]`
    - Returns `dates`

    `get_options_chain(symbol: str, expiration: str) -> str`:
    - Uses `get_cached_text` from `yfinance_cache` with prefix `"tradier_options_chain"`, payload `{"symbol": symbol.upper(), "expiration": expiration}`, TTL `OPTIONS_CHAIN_CACHE_TTL_SECONDS`
    - Inner fetcher calls `_make_request("/markets/options/chains", {"symbol": symbol.upper(), "expiration": expiration, "greeks": "true"})`
    - Extracts `options = data.get("options") or {}`; `option_list = options.get("option") or []`
    - If `isinstance(option_list, dict)`: `option_list = [option_list]` (single-contract normalization)
    - For each contract, flattens greeks: if `contract.get("greeks")` is not None, extracts `delta`, `gamma`, `theta`, `vega` from greeks sub-object, and `iv` from `greeks.get("smv_vol") or greeks.get("mid_iv")`; if greeks is None, sets delta/gamma/theta/vega/iv to None
    - Builds list of flat dicts with keys: `symbol`, `option_type`, `strike`, `expiration_date`, `bid`, `ask`, `volume`, `open_interest`, `delta`, `gamma`, `theta`, `vega`, `iv`
    - Constructs `pd.DataFrame(flat_list)` and returns `df.to_string(index=False)`
    - If `option_list` is empty, returns `"No options data available for {symbol} expiring {expiration}"`

    `get_historical_iv(symbol: str, weeks: int = 52) -> str`:
    - Uses `get_cached_text` from `yfinance_cache` with prefix `"tradier_historical_iv"`, payload `{"symbol": symbol.upper(), "weeks": weeks}`, TTL `HISTORICAL_IV_CACHE_TTL_SECONDS`
    - Inner fetcher:
      1. Calls `get_options_expirations(symbol)` to get list of expiration dates
      2. Filters to expirations within `weeks` weeks from today
      3. For each expiration (limited to weekly intervals — skip if <5 days apart from previous), calls `_make_request` for chain and extracts ATM contract's `smv_vol` (ATM = strike closest to mid of all strikes, or if underlying price available from first contract's `underlying` field)
      4. Builds list of `{"date": expiration_date, "iv": atm_smv_vol}` dicts
      5. Returns `pd.DataFrame(iv_records).to_string(index=False)` or `"No historical IV data available for {symbol}"` if empty

    **Imports:**
    ```python
    import os
    import requests
    import pandas as pd
    from datetime import datetime, timedelta
    from .yfinance_cache import get_cached_text
    ```
