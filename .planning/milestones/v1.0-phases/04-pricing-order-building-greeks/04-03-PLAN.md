    - `_parse_tabular_string(s)` — exact copy.
    - `_get_strategy_type(strategy: str) -> str` — returns normalized strategy name: "long_call", "long_put", "bull_call_spread", "bear_put_spread", "iron_condor", "long_straddle", "long_strangle", "covered_call", "cash_secured_put", "calendar_spread". Use same substring matching from strike_expiry_selector._get_leg_types.
    - `_compute_payoff(strategy_type, legs_data, net_debit_credit)` — returns dict with `max_profit`, `max_loss`, `breakeven` per strategy payoff formulas from RESEARCH.md. For unlimited profit, use string `"unlimited"`. For multi-breakeven (iron condor, straddle, strangle), format as `"lower_be/upper_be"`.

    Factory `create_options_legs_builder(llm)`:
    1. Parse `state["options_legs"]` with LEG_PATTERN. If no matches, return `{"options_legs": "No order — contract selection failed"}`.
    2. For each leg, fetch chain: `route_to_vendor("get_options_chain", ticker, expiry)`, parse, find matching strike+option_type row, extract bid/ask.
    3. Compute mid = (bid+ask)/2.0. Limit price = mid (per locked decision).
    4. Wide spread check: `spread = ask - bid; is_wide = (spread/mid) > 0.10 if mid > 0 else True`. Flag = "[WIDE_SPREAD]" or "[OK]".
    5. Format leg line: `"LEG {n}: {action} {type} {ticker} {expiry} ${strike:.2f} limit={mid:.2f} qty=1 [{flag}]"`.
    6. Compute net_debit_credit: `sum(sign * mid for each leg)` where sign = +1 for BUY, -1 for SELL. Positive = debit, negative = credit.
    7. Compute payoff via `_compute_payoff(strategy_type, legs_data, net_debit_credit)`.
    8. Format NET line: `"NET: debit={net:.2f} max_profit={mp} max_loss={ml} breakeven={be}"`. Use "credit" key if net is negative.
    9. Return `{"options_legs": "\n".join(leg_lines + [net_line])}`.

    Do NOT write to messages. Do NOT use LLM.

    Run tests — all must PASS.
