    Module docstring: "Options pricing agent factory. Computes Black-Scholes theoretical value per leg, net structure value, market mid, edge ($ and %), then uses a single LLM call to write a one-line verdict. Architecture: single-pass (Python computes all numeric metrics; LLM writes narrative verdict). LLM parameter used for verdict generation."

    ```python
    import io
    import re
    from datetime import date
    from typing import Optional
    import pandas as pd
    from langchain_core.prompts import ChatPromptTemplate
    from tradingagents.agents.options.utils.black_scholes import call_price, put_price
    from tradingagents.dataflows.interface import route_to_vendor
    from tradingagents.dataflows.config import get_config
    ```

    Constants:
    - `LEG_PATTERN = re.compile(r"LEG\s+(\d+):\s+(BUY|SELL)\s+(CALL|PUT)\s+(\S+)\s+(\S+)\s+\$([0-9.]+)\s+delta=([0-9.]+)\s+OI=(\d+)\s+\[(PASS|LIQUIDITY FAIL)\]")`
    - `SYSTEM_PROMPT` — use angle-bracket placeholders (NOT curly braces): instruct LLM to output exactly one line with format: `"<verdict_label>: <explanation>"`. Verdict labels: "Positive edge", "Fairly priced", "Overpriced". Tell LLM: "No preamble, no postamble — output the single verdict line only."
    - `DATA_TEMPLATE` — use curly-brace `.format()` for Python string formatting of the data block (this is the human message, NOT a LangChain template). Include: ticker, trade_date, per-leg table (leg_num, action, type, strike, expiry, bs_theoretical, market_mid, edge_pct), net structure values.

    Helpers (duplicated locally per established pattern):
    - `_parse_tabular_string(s: str) -> Optional[pd.DataFrame]` — exact copy from strike_expiry_selector.py

    Factory function `create_options_pricing_agent(llm)`:
    1. Parse `state["options_legs"]` using LEG_PATTERN. If no matches (e.g., LIQUIDITY FAIL), return `{"options_pricing_report": "No pricing available — contract selection failed (LIQUIDITY FAIL)"}`.
    2. Read config: `r = float(get_config().get("options_risk_free_rate", 0.05))`.
    3. Extract dividend yield: parse `state.get("fundamentals_report", "")` for `dividendYield` via regex `r"dividendYield[:\s]+([0-9.]+)"`. If not found, `q = 0.0`.
    4. Get trade_date from `state["trade_date"]`. Compute T per leg: `(date.fromisoformat(expiry) - date.fromisoformat(trade_date)).days / 365.25`.
    5. For each parsed leg:
       a. Fetch chain to get bid/ask: `chain_str = route_to_vendor("get_options_chain", ticker, expiry)`, parse with `_parse_tabular_string`, filter to matching strike and option_type, extract bid/ask, compute `mid = (bid + ask) / 2.0`.
       b. Get IV from chain (column `iv` or `smv_vol`) for matching strike/type. If not found, use 0.25 as fallback.
       c. Compute BS: `theo = call_price(S, K, T, r, q, sigma)` for CALL, `put_price(...)` for PUT. `S` = underlying price from chain data (look for `underlying` column, or use last close from state if unavailable).
       d. Edge: `edge_pct = (theo - mid) / mid * 100 if mid > 0 else 0.0`. `edge_dollar = theo - mid`.
    6. Net structure: `net_theo = sum(sign * theo for each leg)` where sign = +1 BUY, -1 SELL. Same for net_mid, net_edge.
    7. Determine verdict label: `edge_pct > 5.0` -> "Positive edge", `edge_pct < -5.0` -> "Overpriced", else "Fairly priced".
    8. Format DATA_TEMPLATE with all computed values.
    9. LLM call: `prompt = ChatPromptTemplate.from_messages([("system", SYSTEM_PROMPT), ("human", data_content)])`, `result = (prompt | llm).invoke({})`.
    10. Return `{"options_pricing_report": result.content}`.

    Do NOT write to state["messages"]. Do NOT re-fetch from Tradier for pricing inputs (chain fetch is for bid/ask/IV only, which is needed for market mid).

    Run tests — all must PASS.
